**Alimzhan Almukhambetov · IT-2510**

Три самостоятельные формы по официальному `requirements/Assignment 4.pdf`.
Предыдущий проект OFFLINE club для этого задания не используется.

## Запуск

Откройте PowerShell в этой папке:

```powershell
python tools\serve.py
```

Перейдите на **http://127.0.0.1:8044/**. Для остановки нажмите Ctrl+C.
Если порт занят: `python tools\serve.py --port 8045` и откройте порт 8045.

HTML-файлы можно открыть напрямую для просмотра и проверки ограничений полей.
Для успешной демонстрационной отправки нужен указанный локальный сервер: обычный
`python -m http.server` не обрабатывает POST. Python 3 использует только стандартную библиотеку.
Bootstrap 5.3.8 и Montserrat включены в проект; интернет для форм не нужен.

## Проверено

- Все 32 примера из таблицы Task 2 дали ожидаемый результат.
- Дополнительно прошли 16 проверок границ и 2 проверки ограничения максимальной длины.
- Ошибки не видны при открытии; короткое имя после ввода и Tab показывает сообщение.
- Неверная регистрация блокируется; правильная переходит на `complete.html`.
- Task 1: ширины 375/1280 px; на телефоне Find trains выше Clear; reset очищает все элементы.
- Task 1 и Task 3: весь сценарий заполнения и отправки пройден клавиатурой.
- Task 3: все элементы имеют `name`, уникальные `id` и связанные подписи; мобильный вид без горизонтального скролла.
- Официальный W3C Nu HTML Checker: 0 ошибок, 0 предупреждений для всех пяти HTML-страниц.
- В страницах нет JavaScript, `novalidate` или `pattern`. Собственный CSS не использует абсолютное позиционирование или фиксированную ширину макета.

Ограничения браузера проверялись реальным вводом: `minlength` не следует проверять только
присваиванием значения скриптом. Дата отображается согласно языку браузера, но HTML-значение
всегда имеет вид `YYYY-MM-DD`. Проверки выполнены в Chrome под Windows 14 октября 2026.

Формы учебные. Сервер слушает только `127.0.0.1`, не создаёт настоящих бронирований и
отбрасывает POST-данные без сохранения и логирования. Используйте вымышленные данные и пароль.
HTML-валидация не заменяет проверку на сервере в настоящем приложении.

## Что осталось перед сдачей

**Публикация на GitHub не выполнялась по прямому указанию пользователя.**
Преподаватель требует исходники в GitHub и ссылку на репозиторий в отчёте. Пока реальной
ссылки нет, отчёт явно помечает этот пункт как незавершённый. Не подставляйте ссылку на
WEB-midterm: эта работа в нём не опубликована.

После разрешённой публикации добавьте фактический URL в отчёт. С установленными
`reportlab`, `Pillow` и `pymupdf` его можно пересобрать так:

```powershell
python tools\build_report.py --repository-url https://github.com/YOUR_ACCOUNT/YOUR_REPOSITORY
```

Перед сдачей прочитайте отчёт и объясните код самостоятельно: защита обязательна и даёт
50 баллов из 100. В Moodle ничего не загружено, тесты Moodle не запускались.
